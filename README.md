# ZK Tech Solutions — Modern Animated Home Page

A high-performance, fully animated home page redesign for **ZK Tech Solutions**, built with **React, Vite, GSAP, Lenis, and React Three Fiber**.

The website combines modern UI/UX, smooth scrolling, parallax interactions, WebGL-based 3D visuals, responsive layouts, and performance-focused animations to create a premium digital experience.

**Live Website:** https://www.zktechsolutions.org/

---

## 🚀 Technology Stack

- **React** — Component-based frontend architecture
- **Vite** — Fast development and production build tooling
- **GSAP** — Advanced animations and ScrollTrigger interactions
- **Lenis** — Smooth scrolling
- **React Three Fiber** — WebGL-powered 3D hero experience
- **Three.js / Drei** — 3D rendering and supporting utilities
- **CSS** — Custom responsive styling and visual effects
